How to use this project

First rebuild a compatible F3 dataset with python app/backfill.py --range START END --events. The dataset must contain five CNN input channels, timestamp-sorted samples, later F3 proxy labels, and the F3 advection baseline. Then run python app/cnn_benchmark.py or trigger the cnn-evaluation workflow.

The report only supports a claim of added skill when the chronological holdout has sufficient positives and the CNN improves both PR-AUC and Brier score against the baseline. A blocked or no-skill result is a useful result: it means the project does not yet have evidence that the CNN helps.

Inputs and proxy labels: HKO F3 Gridded Rainfall Nowcast. The target is a later F3 grid, not independent gauge ground truth. For official forecasts and warnings, use Hong Kong Observatory. View source on GitHub.
